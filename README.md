# Taawon

Taawon is a website that lists Moroccan artisan cooperatives. It helps people discover the craftspeople and their products, and get in touch with them directly, with no middlemen.

## Pages

| Page | Description |
|------|-------------|
| `index.html` | Home page |
| `cooperatives.html` | Directory of cooperatives |
| `cooperative.html` | Detail page for a single cooperative: products, price breakdown and regions |
| `a-propos.html` | Mission, impact figures, core principles, ethics charter and testimonials |
| `partenaire.html` | Application form for cooperatives who want to join the directory |
| `erreur.html` | 404 error page |

## Features

- Directory of cooperatives from across Morocco
- Product listings with transparent pricing
- Application form with built-in validation (email, Moroccan phone number, required fields)
- Responsive layout

## Built with

- HTML5
- CSS
- [Tailwind CSS](https://tailwindcss.com/) (via CDN)

## Getting started

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/taawon.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

No build step or installation is required.
